## 🏗️ System Architecture Overview

The GoldSmith system is a comprehensive jewelry manufacturing and sales management platform featuring:

- **Gold-based accounting** with pure gold weight tracking
- **Manufacturer management** with gold transit tracking
- **Customer order processing** with delivery management
- **GAAP-compliant accounting** with accrual-based revenue recognition
- **Real-time inventory** and balance management

For detailed technical information, start with **[ACCOUNTING_SYSTEM_TECHNICAL_DOC.md](03_Technical_Documentation/ACCOUNTING_SYSTEM_TECHNICAL_DOC.md)**.
